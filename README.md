# ระบบบัตรนักศึกษา

โปรเจ็กต์ Python OOP สำหรับเก็บข้อมูลนักศึกษา ตรวจสอบข้อมูลบัตร และสร้างหน้า HTML สำหรับดูหรือพิมพ์บัตร

## โครงสร้างโปรเจ็กต์

- `assets/photos/` เก็บโลโก้มหาวิทยาลัยและรูปนักศึกษา
- `src/models/` โมเดลนักศึกษาและบัตร
- `src/services/` การสร้างและตรวจสอบบัตร
- `src/utils/` ฟังก์ชันวันที่ภาษาไทย
- `src/views/` สร้างหน้า HTML ของบัตร
- `tests/` ชุดทดสอบ

## เริ่มใช้งาน

ใช้ Python 3.10 ขึ้นไป:

```powershell
python -m pip install -r requirements.txt
python main.py
```

โปรแกรมจะสร้าง `student_card.html` ที่โฟลเดอร์หลัก เปิดไฟล์นี้ในเบราว์เซอร์เพื่อดูบัตร

## ทดสอบ

```powershell
python -m pytest tests -v
```

ข้อมูลตัวอย่างใน `main.py` ใช้ชื่อ นาย ทับตะวัน งามดี รหัสนักศึกษา 674259015 และสาขาวิศวกรรมซอฟต์แวร์ รูปและโลโก้อยู่ใน `assets/photos/`
